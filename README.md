# Omar Alakkad

Personal portfolio: audit, risk, compliance, AML/CFT and ERP systems.

- `index.html`: home page
- `ultimate-erp.html`: Ultimate ERP case study
- `assets/site.css`: shared styles
- `shots/`: screenshots. To add product screens to the case study, put the image in `shots/` and list it in `shots/manifest.json`, for example
  `[{"file":"dashboard.webp","title":"Dashboard","caption":"What it shows."}]`

Static site, no build step. Served with GitHub Pages.
